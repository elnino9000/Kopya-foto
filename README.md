# Kopya Foto

Galerideki birebir aynı ve benzer fotoğrafları bulur, sonuçları gruplar halinde gösterir.
Silinecekleri sen seçersin; her gruptan en iyi (en yüksek çözünürlüklü) fotoğraf kalır.

- Birebir aynı: dosyalar bayt bayt karşılaştırılır (MD5).
- Benzer: küçük resim parmak izi (dHash) ile karşılaştırılır.
- Her şey telefonda yapılır, fotoğraflar dışarı gönderilmez.
